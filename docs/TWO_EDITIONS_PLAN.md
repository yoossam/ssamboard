# 쌤보드 두 판 계획 — 서버 있는 판 · 서버 없는 판

2026-11-27 선생님 결정: "서버 없는 판과 서버 있는 판 두 가지로 개발을 동시에 진행하자."
선생님 운영본은 지금처럼 운영 서버로 쓰고, 공개판은 **설치 없이 주소만 열면 쓰는 판(자료는 내 구글 드라이브)**을 기본으로 한다.

## 0. 두 트랙 — 쓰는 사람이 고른다

2026-11-27 선생님: "서버용으로 쓸 사람과 구글 클라우드용으로 쓸 사람 두 가지 트랙으로 설정해서 쓸 수 있게."

| 트랙 | 고르는 사람 | 설정하는 곳 |
|---|---|---|
| **① 구글 드라이브 트랙**(서버 없음) | 설치가 부담스러운 대부분의 선생님 | 공용 주소를 열면 첫 화면 "구글 드라이브에 저장하며 시작" → 구글 로그인 → Claude 열쇠. 저장소를 복사해 쓸 때는 `.env` 에 `VITE_EDITION=local`·`VITE_GOOGLE_CLIENT_ID` |
| **② 서버 트랙**(내 서버) | 학교·개인 서버나 늘 켜 둔 컴퓨터가 있는 사람, 선생님 운영본 | `./scripts/install.sh` → `VITE_EDITION=server`(기본값) |

- 공개 README 첫머리에 두 트랙을 나란히 두고 "어느 쪽?" 표(설치 필요·자료 위치·정해진 시각 알림·여러 사람 공유)를 단다.
- 두 트랙은 같은 코드·같은 화면이다. 빌드할 때 `VITE_EDITION` 하나로 갈린다. 화면 설정 → 정보에 "지금 트랙: 구글 드라이브 / 내 서버"를 보인다.
- 트랙 옮기기: 드라이브 트랙은 설정 → 드라이브 → 내보내기/가져오기(`ssamboard-data.json`)가 있다. 서버 트랙의 같은 기능은 L2(가져올 때 사용자 id 를 지금 로그인한 사람으로 다시 잇는 일이 남음).

## 1. 두 판 한눈에

| | 서버 있는 판 (지금) | 서버 없는 판 (새로) |
|---|---|---|
| 누가 | 선생님 운영본(운영 서버), Docker 를 쓸 수 있는 사람 | 공개판 기본 — 다른 선생님 누구나 |
| 시작하기 | `./scripts/install.sh`(Docker·도메인·터널) | 주소 열기 → 구글 로그인 → Claude 열쇠 넣기 |
| 화면 | 같은 화면(apps/web) | 같은 화면(apps/web), GitHub Pages 에 올림 |
| 데이터베이스 | PostgreSQL 16(서버) | **PGlite — 브라우저 안에서 도는 같은 Postgres** |
| 자료가 있는 곳 | 서버 디스크 | 브라우저 + **내 구글 드라이브 앱 폴더**(맞춤·백업) |
| 로그인 | 구글 또는 이메일·암호 + PIN | 구글 로그인(드라이브 권한과 한 번에) |
| AI | 서버가 Claude 를 부름(열쇠는 서버에 암호화) | 브라우저가 Claude 를 바로 부름(열쇠는 그 브라우저에만) |
| 정해진 시각에 하는 일 | 서버 일꾼이 늘 함 | 쌤보드를 열어 둔 동안만 |

## 2. 핵심 생각 — "서버 코드를 그대로 브라우저에서" (2026-11-27 시험으로 바꿈)

처음 계획은 기능 코드를 `packages/core` 로 옮겨 적는 것이었지만, 시험해 보니 **서버 코드(apps/api/src)를 한 줄도 고치지 않고 브라우저에서 돌릴 수 있어** 그 길로 바꿨다.

- **데이터베이스**: PGlite(브라우저 안 PostgreSQL)라서 서버의 마이그레이션·SQL 이 그대로 돈다. 서버 서비스는 DB 를 `query`·`one`·`tx` 로만 쓰므로 같은 모양의 `LocalDb`(apps/local/src/db.ts)를 넘긴다.
- **Nest 대체품**: 빌드할 때 `@nestjs/common`·`pg`·`node:*`·`config.ts`·`common/crypto.ts` 를 브라우저 대체품으로 바꿔 끼운다(apps/local/build/redirects.mjs — Vite·esbuild 둘 다).
  대체 데코레이터가 주소·인자 자리를 적어 두고, `LocalRouter`(apps/local/src/router.ts)가 화면의 `/api/…` 요청을 **서버와 같은 컨트롤러 메서드**로 잇는다. 주소를 따로 적지 않는다.
- **화면은 fetch 하나만 바꾼다**: `apps/web/src/lib/api.ts` 의 `setFetcher()` — 구글 드라이브 트랙은 브라우저 안 서버의 fetch(진짜 `Response`, AI 흘려보내기도 같은 SSE)를 끼운다.
- **서버에만 있는 것**: 웹훅(받아 줄 서버가 필요), 정해진 시각 일꾼(시트 자동 맞춤·알림). 나머지는 두 트랙 모두.

```
apps/api     서버 트랙(그대로). 기능은 여기에 넣는다 → 두 트랙에 함께 들어간다
apps/local   구글 드라이브 트랙 묶음: 대체품(shim)·LocalDb·LocalRouter·드라이브 맞춤·구글 로그인·시작(index.ts)
apps/web     같은 화면. VITE_EDITION=local 이면 시작 화면(local-shell/)을 거쳐 브라우저 안 서버로 붙는다
```

**규칙(동시 개발)**: 새 기능은 서버 코드에 넣는다. 서버 코드가 새 Node 모듈을 부르면 `npm run build:local` 이 실패하므로 대체품을 더하거나 그 기능을 드라이브 트랙에서 막는다.
시험은 `npm test`(서버 시험 + apps/local 의 PGlite 시험)가 두 트랙을 함께 본다.

## 3. 서버 없는 판 — 자료와 드라이브

- **바로 저장**: 모든 쓰기는 브라우저 안 PGlite(`idb://ssamboard`)에 바로. 화면이 기다리지 않는다.
- **드라이브 맞춤**: 바뀐 뒤 10초 조용하면, 그리고 창을 닫거나 숨길 때 `ssamboard-data.json`(사용자 표의 줄을 JSON 으로)을
  드라이브 **앱 폴더(appDataFolder)** 에 올린다. 통째 파일(약 4MB, 대부분 Postgres 기본 표)이 아니라 내 자료만 올려 작게 둔다.
- **다른 기기에서 열 때**: 드라이브 파일이 이 기기의 마지막 맞춤보다 새것이면 받아서 채운다.
- **두 기기에서 동시에 고쳤을 때**: 올리기 전에 드라이브 파일 판 번호를 보고, 다른 기기가 먼저 올렸으면
  "다른 기기에서 바뀌었습니다 — 그쪽 것 받기 / 이 기기 것 올리기"를 묻는다(혼자 쓰는 앱이라 드묾).
- **하루 백업**: 하루 한 번 `backup-YYYY-MM-DD.json` 을 앱 폴더에 남기고 14개까지 둔다. 설정에서 되살리기.
- **한도**: 드라이브는 하루 요청 한도가 없고 사용자당 분당 약 6,500번 쓰기 — 걸리지 않는다(구글 문서, 2026-11-27 확인).
- **첨부 파일**: AI 에 붙이는 파일은 지금처럼 저장하지 않고 보낸다. 보관이 필요해지면 드라이브에 따로.

## 4. 서버 없는 판 — 로그인·권한·AI

- **구글 로그인**: Google Identity Services 토큰 방식(브라우저만). 권한은 `drive.appdata`(앱 폴더) 하나로 시작.
  시트 가져오기는 `drive.file`(고른 파일만)을 더하고, 설문(`forms.body`)은 구글 검토가 필요할 수 있어 맨 뒤.
- **구글 OAuth 클라이언트**: 공용 주소(아래 §7 결정)용 하나를 선생님 구글 클라우드에 만든다. 저장소를 복사해 자기 주소로 띄우는 사람은
  README 대로 자기 클라이언트 ID 를 넣는다(`VITE_GOOGLE_CLIENT_ID`).
- **Claude**: 브라우저에서 `api.anthropic.com` 을 바로 부른다(`anthropic-dangerous-direct-browser-access` 머리글). 열쇠는 그 브라우저(IndexedDB)에만,
  드라이브에도 올리지 않는다. 한 달 사용 한도는 브라우저가 센다.
- **화면 잠금**: PIN 은 "자리 비움 가림막"으로만(그 기기 안). 진짜 보호는 구글 로그인과 기기 잠금.

## 5. 보안 — 서버 없는 판에서 새로 지킬 것

- 열쇠가 브라우저에 있으니 **남의 스크립트가 끼면 안 된다**: CSP(`script-src 'self'`, `connect-src` 는 api.anthropic.com·googleapis·accounts.google.com 만),
  바깥 스크립트·분석 도구 넣지 않음.
- **AI 화면 블록**: 서버가 주던 격리 틀(`view-frame.ts`)을 `sandbox` iframe(`srcdoc`, allow-same-origin 없음) + 일꾼으로 옮기고 GPT·제미나이 검토를 다시 받는다.
  격리를 풀어 주는 변경은 하지 않는다(그 파일 맨 위 까닭 그대로).
- 드라이브 앱 폴더는 그 앱만 읽고 쓸 수 있다. 운영자(선생님)는 다른 선생님 자료를 볼 수 없다 — README 에 적는다.

## 6. 단계

| 단계 | 내용 | 상태 |
|---|---|---|
| **S0 기반** | 화면 fetch 끼우기, 서버 코드를 브라우저에서 돌리는 틀(대체품·라우터·LocalDb), 두 트랙 시험 | 끝(2026-11-27) |
| **L1 처음 써 보는 판** | 트랙 고르기 화면, 구글 로그인, 드라이브 맞춤(충돌·하루 백업), 보드·할 일·일정·메모·표·휴지통·설정, AI 대화(브라우저가 Claude 직접), 설정 → 드라이브(저장·백업 되살리기·내보내기/가져오기) | 끝(2026-11-27, 가짜 구글로 브라우저 시험) |
| **L2** | 두 트랙 공통 자료 옮기기(apps/api/src/data/transfer.ts, 서버 트랙 설정 → 자료), 파일로 표 만들기(메모리 디스크·Buffer), 서비스 워커(인터넷 없이 열기), GitHub Pages 자동 배포 | 끝(2026-11-27) |
| **L3** | AI 화면 블록(샌드박스 srcdoc 틀 + 문서 안 정책 + 서버와 같은 준비 코드 view-inner.js), 시트 가져오기·설문(서버 connectors 코드 그대로, 구글 토큰만 브라우저 로그인 것 — stub/google.ts) | 끝(2026-11-27, 가짜 구글로 브라우저 시험) |
| 남음 | 웹훅·정해진 시각 일꾼은 서버가 있어야 해서 드라이브 트랙에 없음. 설문 권한(forms)을 실제 구글에서 확인 | — |

각 단계 끝: 시험(두 트랙) · 타입 · 빌드 · 화면 확인 · 외부 검토 → 선생님 `배포`.

## 7. 선생님이 정할 것

1. **공용 주소**: 공개 저장소의 GitHub Pages 기본 주소(추천 — 손 갈 것 없음) 또는 선생님 도메인의 하위 주소.
2. **구글 클라우드**: 서버 없는 판용 OAuth 클라이언트를 지금 프로젝트에 더할지(추천), 새 프로젝트로 뗄지. 동의 화면은 '프로덕션'으로 게시해야 다른 선생님이 쓸 수 있다.
3. 공개판에 Docker 설치판을 계속 함께 둘지(추천: 둔다 — 같은 코드라 드는 품이 적다).

## 8. 위험

- PGlite 내려받기 약 3MB(처음 한 번, 그 뒤 캐시). 오래된 휴대폰에서 첫 실행이 몇 초 걸릴 수 있다.
- 브라우저가 저장 공간을 비우면 이 기기 자료가 사라진다 → 드라이브에서 다시 받는다(그래서 드라이브 맞춤이 필수).
- `core` 로 옮기는 동안 서버 판이 망가지지 않게 S0 은 작은 커밋으로 나누고, 매번 지금 시험 72개가 그대로 통과해야 한다.
