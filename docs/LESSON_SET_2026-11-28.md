# 수업 세트 — 수업 자료·도구를 한 묶음으로 (세 모델 합의, 2026-11-28)

> **방향이 바뀐 옛 안(2026-11-28 저녁 선생님)**: 수업은 시간표·차시별로 미리 만들지 않고 수업 보드에서 즉석으로 한다 → [CLASS_BOARD_2026-11-28.md](CLASS_BOARD_2026-11-28.md). 연결 가능 여부(캔바·틸더스·구글)는 그대로 참고한다.

선생님 요청(11-28):
> "수업 준비에 어떤 도구가 들어가야 할지 더 합의해 봐. 캔바나 다른 도구 링크를 바로 넣고 관리하고, AI API로 그 도구에 로그인해서 하나의 수업 세트로 만들어 놓고, 수업 때는 그걸 누르면 연결되게 할 수 있겠니?"

앞 토론: [LESSON_PREP_2026-11-28.md](LESSON_PREP_2026-11-28.md)(표 "수업 준비", 한 교시 = 한 줄).
기준: **편리한 업무 처리와 결과 확인.** 자료를 만드는 일은 원래 도구(캔바·구글 등)에 맡기고, 쌤보드는 **묶고, 준비됐는지 확인하고, 수업 때 바로 여는 일**을 맡는다.

## 1. 답: 할 수 있나

| 요청 | 답 | 방법 |
|---|---|---|
| 캔바·다른 도구 링크를 넣고 관리 | **됨(1단계)** | 링크를 붙여 넣으면 주소를 보고 종류(캔바·슬라이드·영상·띵커벨…)를 알아내 세트에 넣는다 |
| 하나의 수업 세트로 묶기 | **됨(1단계)** | 표 "수업 세트"에 묶고, "수업 준비" 줄에 세트 이름을 적는다 |
| 수업 때 누르면 연결 | **됨(1단계, 작은 새 화면 하나)** | [수업 시작] → 큰 단추가 순서대로 보이고, 하나씩 눌러 연다 |
| AI API로 도구에 로그인 | **방식을 바꿔서 일부 됨** | 비밀번호를 받아 AI가 대신 로그인하는 것은 약관·보안 때문에 하지 않는다(세 모델 같은 의견). 대신 공식 **계정 연결(OAuth)**을 쓴다. 선생님이 한 번 "허락"을 누르면 쌤보드가 허락받은 범위 안에서 그 도구의 자료를 찾는다. **캔바(Connect API)·구글은 이렇게 된다(2단계)**. 아이스크림 쌤·띵커벨·클래스카드·카훗 등 공개 API가 없는 도구는 **링크만** 쓴다. 브라우저에 이미 로그인돼 있으면 링크를 누르는 대로 바로 열린다 |

## 2. 수업 세트에 들어갈 것(합의)

| 꼭 | 종류(선택 칸) | 예 |
|---|---|---|
| ✔ | 슬라이드 | 캔바, 구글 슬라이드, PPT(드라이브) |
| ✔ | 영상 | 유튜브, 에듀넷, 아이스크림 쌤 |
| ✔ | 학습지 | 한글·PDF(드라이브 링크) |
| ✔ | 참여·퀴즈 | 띵커벨, 패들렛, 카훗, 구글 설문, 틸더스 런치패드 |
| ✔ | 학생에게 줄 링크 | 위 항목 중 '학생 공개'에 체크한 것 |
|  | 기타 | 타이머·판서 같은 도구는 따로 기능을 만들지 않고, 필요하면 링크로 넣는다 |

빼는 것: 쌤보드 안에서 자료 만들기(편집기), 문항 은행, 학생별 기록.

## 3. 자료 모양

표를 두 개로 나눠, 새 블록 종류 없이 있는 표를 쓴다.

**"수업 준비"**(앞 토론의 8칸)에 **세트** 칸(글) 하나를 더한다. 예: `과학 3-4 용해`.

**"수업 세트"**(새 표, 7칸)

| 칸 | 종류 | 예 |
|---|---|---|
| 세트 | 글 | 과학 3-4 용해 |
| 순서 | 숫자 | 1 |
| 종류 | 선택(슬라이드·영상·학습지·참여·기타) | 슬라이드 |
| 제목 | 글 | 용해 도입 슬라이드 |
| 주소 | url | https://www.canva.com/design/… |
| 학생 공개 | 체크 | ☐ |
| 확인 | 체크 | ☑ (링크가 열리는지, 공유 권한이 맞는지 선생님이 확인) |

- **다시 쓰기**: 다음 해나 다른 반에서 쓸 때는 [세트 복사]로 새 이름을 붙여 쓴다. 이때 '확인'은 모두 풀려서, 링크와 권한을 다시 보게 된다.
- **오래 둘 파일**: AI가 고친 학습지 파일은 하루만 보관된다. 오래 둘 파일은 드라이브에 저장한 뒤 그 링크를 넣는다. 2단계에서는 '드라이브에 저장하고 세트에 넣기'를 한 번에 한다.

## 4. 수업 때 화면 — [수업 시작]

- "수업 준비" 블록의 오늘 줄 또는 세트 이름을 누르면 **수업 화면**이 열린다.
  - 큰 단추가 순서대로 늘어선다(1 슬라이드 → 2 영상 → 3 참여 → 4 학습지).
  - [다음]을 누르면 다음 단추가 강조된다.
- **한 번에 하나씩 연다.** 한 번 눌러 여러 탭을 여는 것은 팝업 차단에 걸리므로 하지 않는다(세 모델 합의). 각 단추는 새 탭으로 열려, 수업 화면이 남아 있다.
- 교실 TV나 PC에서는 큰 글씨로, 휴대폰에서는 세로 목록으로 보인다.
- **학생에게 줄 때**는 기존 공유 링크를 쓴다. 학생 공개에 체크한 항목만 담기고, 로그인 없이 읽기만 된다. 원래 자료(캔바 등)의 '보기 권한'은 선생님이 그 도구에서 열어 두어야 한다. 그래서 '확인' 칸이 있다.
- 링크를 열었다고 수업을 끝낸 것으로 치지 않는다. 결과는 [수업 후 정리]에서 선생님이 확정한다.

## 5. AI가 할 일 / 하지 않을 일

| 함(계획 → 승인) | 하지 않음 |
|---|---|
| 링크 여러 개를 붙여 넣으면 종류·제목을 정리해 세트에 줄 추가. 종류는 주소 모양으로 먼저 판단하고, AI는 제목·순서만 제안 | 비밀번호 받기, 대신 로그인, API 없는 사이트 자동 조작 |
| '활동 흐름'과 맞춰 보고 빠진 자료 알려 주기(예: "실험 활동인데 학습지가 없습니다") | 로그인해야 보이는 내용을 읽었다고 말하기 |
| (2단계, 캔바 연결 뒤) 단원 이름으로 내 캔바 디자인을 찾아 후보 보이기 → 고른 것만 넣기 | 자료를 마음대로 학생 공개로 바꾸기 |
| [내일 수업 차리기]에서 세트가 빈 차시 알려 주기 | 수업 완료 확정 |

## 6. 단계

**1단계(작은 코드)**
1. 주소 모양으로 종류를 알아내는 규칙 하나(공용). 캔바·구글 슬라이드·문서·유튜브·패들렛·띵커벨·카훗·에듀넷·아이스크림·틸더스.
2. "수업 세트" 표 틀과 "수업 준비"의 세트 칸.
3. AI 도구 `add_lesson_links`: 붙여 넣은 링크를 세트에 줄로 더한다(계획 → 승인 → 되돌리기).
4. **수업 화면**(창 하나): 세트의 항목을 순서대로 큰 단추로 보이고, [다음]과 [학생용 공유 링크]를 둔다.
5. [세트 복사]: 새 이름으로 복사하고 '확인'을 푼다.
6. 사용 안내와 시험. 두 판(서버·드라이브)에 같이 들어간다.

**2단계**
- **캔바 연결(OAuth)**: 디자인 찾기와 PDF 내보내기. 먼저 선생님이 캔바 개발자 화면에서 통합 앱을 한 번 등록해야 한다. 공개판은 쓰는 사람마다 따로 등록해야 하므로 선택 기능으로 둔다.
- 드라이브에 저장하고 바로 세트에 넣기(지금 권한 drive.file 안에서).
- 오늘 확인 줄에 '내일 세트가 빈 수업 N'을 더한다.
- (선택) 틸더스 런치패드와 잇기. 학생 화면의 "지금 할 활동"을 세트 순서와 맞춘다. 선생님이 이미 쓰는 곳이라 붙이기 쉽지만, 범위가 커서 나중에 정한다.

## 7. 선생님이 정할 것

- 1단계를 만들지(만들어도 배포는 `배포` 때).
- 캔바 연결(2단계)을 할지. 하면 캔바 개발자 등록을 한 번 해 주셔야 한다.
- 틸더스 런치패드와 이을지(나중).
