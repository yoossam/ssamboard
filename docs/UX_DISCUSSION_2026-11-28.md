# 쌤보드 UX/UI 토론 — 2026-11-28 (Claude·Codex·제미나이)

선생님 지시: "앞으로 어떻게 UX·UI를 다듬으면 좋을지 셋이 토론해 결과를 남기고, 추천을 그대로 반영해 고친 뒤 다시 리뷰".
**기준(선생님 강조): 이 앱의 정체성은 편리한 학교 업무 처리와 결과 처리 확인.**
쓰는 장면: 교사가 쉬는 시간 5~10분에 휴대폰이나 교실 PC로 연다.

진행: 1라운드에서 셋이 따로 안을 냄 → Claude가 합친 초안(A~J) → 2라운드에서 Codex·제미나이가 찬성·수정·반대를 내고 오늘 만들 6개를 고름 → Claude가 최종 결정.
각자의 원문은 저장소 밖(작업 폴더)에 두었다. 여기에는 요점만 남긴다.

## 1라운드 — 셋이 본 가장 큰 문제

| 문제 | 낸 쪽 |
|---|---|
| **처리한 결과가 AI 대화 속 계획 카드에 묻힌다.** 창을 닫으면 무엇이 바뀌었는지, 만든 파일·링크가 어디 있는지 다시 찾기 어렵다. 지난 대화를 다시 열면 계획 카드도 사라졌다 | 셋 다 |
| 첫 화면에 우선순위가 없다. 오늘 마감·승인 대기·새 응답이 묻힌다 | Claude·Codex |
| 블록 머리줄에 단추가 4개 있다. 제목을 누르면 'AI에 알려 주기'가 되고, 머리줄을 끌면 블록이 옮겨진다. 급하게 누르면 실수가 난다 | 제미나이·Codex |
| ≡ 메뉴와 ⋯ 더보기를 나눈 기준이 모호하다 | Claude·제미나이 |
| 휴대폰 2열 타일은 보기만 된다. 할 일을 바로 체크하거나 추가할 수 없다 | 셋 다 |
| AI 입력줄이 빈칸이라 매번 할 말을 생각해야 한다 | Codex·제미나이 |
| 첫 업무 전에 준비할 것이 많다(열쇠 → 꾸미기 → 메뉴 추천) | Codex |

## 2라운드 — 합친 안 A~J에 대한 판단

| 안 | 내용 | Codex | 제미나이 |
|---|---|---|---|
| A | 처리 결과함 | 수정(성공·일부·실패 구분, 할 수 있는 동작만) | 찬성 |
| B | 오늘 확인 요약 줄 | 수정(마감·지연·승인 대기부터, 중복 집계 없이) | 수정(0건은 숨김) |
| C | AI 입력줄 위 빠른 업무 칩 | 찬성(우선 3개) | 찬성 |
| D | 블록 머리줄 정리 | 수정(제목은 제목, 'AI 포함'은 따로 체크) | 수정(선택 상태를 체크로 분명히) |
| E | ≡ = 업무함, ⋯ = 화면·설정 | 수정(블록 추가를 ⋯에 숨기면 못 찾음) | 찬성 |
| F | 휴대폰에서 바로 처리 | 수정(1열·체크·빠른 추가만, 아래 탭은 보류) | 수정(같은 의견) |
| G | 수합 현황(응답 수·마지막 갱신) | 찬성 | 찬성 |
| H | 실수 끌기 막기 | 찬성 | 찬성 |
| I | 첫 안내를 실제 업무부터 | 수정(열쇠가 필요하면 먼저 알림) | 찬성 |
| J | 승인 뒤 바뀐 곳 보이기 | 찬성 | 찬성 |

오늘 만들 6개로 고른 것:
- Codex: A·J·G·F·H·C
- 제미나이: A·J·B·D·H·F

**함께 짚은 위험**
- 되돌리기를 '완전 원상복구'로 오해할 수 있다. 공유 링크·파일·바깥 문서는 다르다.
- 승인한 것과 끝난 것이 헷갈린다. 처리 중·일부 못 함·실패를 구분해야 한다.
- 위쪽 메뉴와 아래 탭에 같은 기능이 겹친다.
- 'AI에 알려 주기'로 고른 블록이 남아 다음 요청에 섞일 수 있다.
- 두 트랙(서버·드라이브)을 각각 확인해야 하고, 사용 안내(guide.html)도 같이 고쳐야 한다.

## 최종 결정 (Claude, 두 모델의 공통 6개 + 한쪽이 고른 2개)

| 순서 | 무엇을 | 받아들일 조건 |
|---|---|---|
| 1 | **A 처리 결과함** — 위쪽 줄 [처리 결과] 단추(승인 대기 수 배지) → 최근 14일 목록 | 상태를 **승인 대기·마무리 중·완료(못 한 것 따로 표시)·되돌림** 네 가지로 구분. 항목마다 할 수 있는 동작만 보인다: [보드에서 보기]·[파일 받기](만료 시각, 지워졌으면 '기간 지남')·[링크 복사](꺼진 링크는 '꺼짐')·[되돌리기](가장 최근 것만). **되돌리기 범위를 문구로 밝힌다** |
| 2 | **J 바뀐 곳 보기** | 승인에 성공하면 바뀐 블록을 몇 초 강조하고, 계획 카드·결과함의 [보드에서 보기]로 그 블록까지 스크롤 |
| 3 | **B 오늘 확인 줄** | 보드 위 한 줄에 승인 대기·지난 마감·오늘 마감·오늘 일정·안 읽은 알림을 보이고, **0건은 숨긴다**. 누르면 그 창으로 간다 |
| 4 | **F 휴대폰 바로 처리** | 1열 목록, 할 일 바로 체크, 시트를 열지 않는 빠른 추가, 글자 16px·누를 곳 44px. **아래 탭은 만들지 않는다**(위쪽과 겹침) |
| 5 | **D 머리줄 정리** | [아이콘·제목·건수] [AI 포함 체크(따로)] [공유(되는 블록만)] [크게 보기] [⋯ 꾸미기·편집·고정]. AI 입력줄에 '블록 N개 · 비우기'를 보이고, 보낸 뒤 자동으로 비운다 |
| 6 | **H 실수 끌기 막기(수정)** | 11-27 선생님 결정("크기를 자유자재로", 편집 모드 없이 옮기기)을 지킨다. 그래서 잠그지 않고 **손잡이(⠿)를 잡을 때만 옮겨지게** 한다. 크기 조절 모서리는 그대로 |
| 7 | **C 빠른 업무 칩 3개** | 통신문 → 일정 / 파일 고치기 / 설문 만들기. 누르면 AI 창이 열리고 필요한 자료(첨부)부터 안내한다 |
| 8 | **G 수합 현황** | 설문·시트에 연결된 표 블록에 '응답 N · 마지막 갱신 시각'과 [새로 읽기]. 명단이 없으니 제출률·미제출은 추정하지 않는다 |

**보류한 것과 까닭**
- E(메뉴 재정렬): Codex의 '블록 추가 발견성' 우려가 있다. 결과함이 생긴 뒤 다시 본다.
- I(첫 안내 순서): 첫 안내는 11-28에 막 만들었다. 대신 빠른 업무 칩을 열쇠 없이 누르면 열쇠 안내로 보낸다.
- 아래 탭: 둘 다 반대했다.

**하지 말 것(셋 공통)**
- 위젯·테마·배치 옵션 늘리기, 설정 탭 늘리기
- 채팅·게시판·결재 같은 협업 확장
- 블록 안의 복잡한 편집기
- 모든 일을 AI 대화로 만들기, 자동 승인
