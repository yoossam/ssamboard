쌤보드 개인정보 처리방침

대상: 쌤보드 구글 드라이브 트랙(이 주소에서 여는 서버 없는 웹앱) · 시행일 2026년 12월 5일(2026년 11월 28일 공고)

바뀐 내용(2026년 11월 28일 공고, 12월 5일 시행) — AI 로 GPT(OpenAI)를 고를 수 있게 되어 제2조·제7조·제11조에 OpenAI 를 더했습니다. GPT 는 이용자가 직접 모델을 고르고 열쇠를 넣었을 때만 쓰입니다. 또 이용자가 직접 만드는 공유 링크(구글 문서로 공개)를 제5조에 적었습니다.

쌤보드 공개판 운영자(이하 “운영자”)는 「개인정보 보호법」 제30조에 따라 정보주체의 개인정보를 보호하고 이와 관련한 고충을 신속하고 원활하게 처리할 수 있도록 다음과 같이 개인정보 처리방침을 수립·공개합니다.

제1조 (개인정보의 처리 목적)

쌤보드는 할 일·일정·표·메모를 한 화면에서 관리하는 교사용 업무 도구입니다. 이 웹앱은 운영자의 서버 없이 이용자의 브라우저 안에서만 동작하며, 아래 목적에 필요한 범위에서 이용자의 기기 안에서 정보를 처리합니다. 운영자는 이 정보를 받거나 열람하지 않습니다.

  1. 로그인한 구글 계정 확인 및 계정별 보드 구분
  2. 보드 자료의 저장, 여러 기기 사이의 동기화, 백업과 복원
  3. 이용자가 요청한 구글 시트 가져오기·구글 설문 만들기와 응답 모으기
  4. 이용자가 요청한 AI 정리·요약 기능 제공

제3조 (개인정보의 처리 및 보유 기간)

  1. 운영자는 개인정보를 보유하지 않습니다.
  2. 이용자 기기와 구글 드라이브의 자료는 이용자가 지울 때까지 남습니다. 드라이브 백업은 하루 한 개씩 최근 14개까지만 남기고 오래된 것은 자동으로 지웁니다.
  3. 구글 접근 토큰은 발급 후 약 1시간, 또는 탭을 닫거나 로그아웃할 때까지 보관합니다.
  4. 표로 만들려고 고른 파일(CSV·엑셀)은 표를 만드는 동안 탭 메모리에만 두고 저장하지 않습니다.

제4조 (개인정보의 파기 절차 및 방법)

운영자가 보유하는 개인정보가 없으므로 운영자의 파기 절차는 없습니다. 이용자는 다음 방법으로 언제든 직접 파기할 수 있습니다.

  1. 이 브라우저의 자료: 앱의 설정 → 드라이브 → 로그아웃(이 기기 자료 지움), 또는 브라우저 설정에서 이 사이트 데이터 삭제
  2. 구글 드라이브의 자료: 구글 드라이브 → 설정 → 앱 관리 → 쌤보드 → “숨겨진 앱 데이터 삭제”

지운 자료는 되살릴 수 없습니다(구글 드라이브에 남은 백업을 지우기 전이라면 앱의 백업 되살리기로 복원할 수 있습니다).

제5조 (개인정보의 제3자 제공)

운영자는 개인정보를 제3자에게 제공하지 않습니다. 이용자가 AI 기능이나 구글 연동 기능을 쓸 때 이용자 브라우저가 해당 서비스에 직접 보내는 경우는 제7조에 적었습니다. 이용자가 공유 링크를 만들면, 고른 블록의 내용이 이용자 구글 드라이브의 구글 문서로 만들어지고 그 링크를 받은 사람이 볼 수 있습니다. 이는 이용자가 직접 정한 공개이며, 끄기를 누르면 공개가 꺼집니다.

제6조 (개인정보 처리의 위탁)

운영자는 개인정보 처리 업무를 위탁하지 않습니다. 이 웹페이지 파일은 GitHub Pages 가 내려 주며, GitHub 은 접속 기록(IP 주소 등)을 자체 정책에 따라 처리할 수 있습니다(GitHub 개인정보 처리방침).

제7조 (개인정보의 국외 이전)

운영자는 개인정보를 국외로 이전하지 않습니다. 다만 이용자가 아래 기능을 쓰면 이용자의 브라우저가 이용자 본인의 계정·열쇠로 국외 사업자에게 직접 정보를 보냅니다. 이는 이용자와 해당 사업자 사이의 이용 계약에 따릅니다.

받는 자(국가)보내는 정보보내는 때와 방법목적보유 기간
Google LLC(미국)로그인 정보, 보드 자료, 시트·설문 요청 내용구글 로그인·저장·시트·설문 기능을 쓸 때, HTTPS 로 전송로그인, 이용자 드라이브 저장, 시트·설문 연동이용자 구글 계정의 설정·정책에 따름(구글 개인정보처리방침)
Anthropic PBC(미국)AI 에게 시킨 말과 그 일에 필요한 보드 내용이용자가 Claude 모델을 고르고 자기 Claude API 열쇠로 AI 기능을 쓸 때만, HTTPS 로 전송AI 정리·요약·화면 만들기Anthropic 의 정책에 따름(Anthropic 개인정보 처리방침)
OpenAI, L.L.C.(미국)AI 에게 시킨 말과 그 일에 필요한 보드 내용이용자가 GPT 모델을 고르고 자기 OpenAI API 열쇠로 AI 기능을 쓸 때만, HTTPS 로 전송AI 정리·요약·화면 만들기OpenAI 의 정책에 따름(OpenAI 개인정보 처리방침)

이용자는 해당 기능을 쓰지 않는 방법으로 국외 전송을 거부할 수 있습니다. 구글 로그인 없이 “이 기기에서만 써 보기”를 고르고 AI 열쇠를 넣지 않으면 어떤 정보도 국외로 보내지 않습니다. 다만 이때는 기기 간 동기화와 AI 기능을 쓸 수 없습니다.

제8조 (구글 사용자 데이터의 처리)

쌤보드는 다음 구글 권한만 요청하고, 적힌 목적에만 씁니다.

  • drive.appdata — 이용자 드라이브 안에 이 앱만 쓰는 숨은 폴더를 만들어 보드 자료와 백업을 저장합니다. 드라이브의 다른 파일은 보거나 바꿀 수 없습니다.
  • openid · email · profile — 로그인한 계정의 이메일과 이름을 확인합니다.
  • drive.file(설정 → 연결에서 시트·설문을 연결할 때만) — 이용자가 직접 고른 구글 시트를 읽어 표로 가져오고, 이용자가 만들라고 한 구글 설문을 만들고 그 응답을 읽습니다. 앱이 만들었거나 이용자가 고른 파일만 다룰 수 있습니다.

구글에서 받은 데이터는 이용자 브라우저와 이용자 드라이브 앱 폴더 밖으로 옮기지 않으며, 예외는 이용자가 AI 에게 시킨 일에 필요한 내용을 이용자의 열쇠로 Anthropic 또는 OpenAI 에 보내는 경우(제7조)뿐입니다. 판매, 광고, 사람이 열람하는 일, AI 모델 학습에는 쓰지 않습니다. 쌤보드가 Google API 에서 받은 정보를 쓰고 다른 곳으로 옮기는 일은 Google API 서비스 사용자 데이터 정책(제한적 사용 요건 포함)을 지킵니다.

제9조 (정보주체의 권리·의무 및 행사 방법)

  1. 정보주체는 언제든지 개인정보 열람, 정정, 삭제, 처리 정지 및 동의 철회를 요구할 수 있습니다.
  2. 모든 자료가 이용자 기기와 이용자 드라이브에 있으므로, 이용자는 앱에서 직접 열람·정정·삭제할 수 있습니다. 설정 → 드라이브 → 내보내기로 보드 전체를 파일로 받을 수도 있습니다.
  3. 동의 철회(구글 권한 거두기): 구글 계정 → 서드 파티 앱 및 서비스에서 쌤보드 연결을 삭제합니다.
  4. 그 밖의 요구나 문의는 제14조의 개인정보 보호책임자에게 할 수 있으며, 법정대리인이나 위임을 받은 사람을 통해서도 할 수 있습니다. 운영자는 개인정보를 보유하지 않으므로, 요구 내용이 운영자가 처리할 수 없는 것이면 그 방법을 안내합니다.
  5. 이용자는 보드에 다른 사람의 개인정보를 입력할 때 관계 법령과 소속 기관의 지침을 지켜야 합니다.

제10조 (만 14세 미만 아동의 개인정보 처리)

쌤보드는 교사 등 성인이 업무에 쓰도록 만든 도구로, 만 14세 미만 아동을 이용자로 두지 않으며 아동의 개인정보를 직접 수집하지 않습니다.

제11조 (개인정보의 안전성 확보 조치)

  1. 저장 최소화: 운영자 서버를 두지 않아 운영자 쪽에 개인정보가 모이지 않습니다.
  2. 전송 구간 보호: 모든 통신은 HTTPS 로 암호화합니다.
  3. 접근 제한: 구글 권한은 앱 전용 폴더와 이용자가 고른 파일로 좁혔습니다. 페이지에는 정보를 보낼 수 있는 곳을 Google·Anthropic·OpenAI 로만 제한하는 보안 정책(CSP)을 걸었습니다.
  4. 열쇠 보호: AI API 열쇠(Claude·GPT)는 드라이브·백업·내보내기 파일에 담지 않습니다. 구글 접근 토큰은 로그인한 계정을 확인한 뒤에만 쓰고, 탭이 닫히면 사라집니다.
  5. 격리 실행: AI 가 만든 화면 코드는 바깥과 통신할 수 없는 격리된 틀 안에서만 실행합니다.
  6. 공개 검증: 앱의 소스 코드를 모두 공개해 누구나 처리 방식을 확인할 수 있습니다.

제12조 (개인정보 자동 수집 장치의 설치·운영 및 거부)

쌤보드는 쿠키를 쓰지 않습니다. 앱이 동작하는 데 필요한 자료(보드 자료, 선택한 사용 방식, 오프라인 실행용 앱 파일)는 브라우저의 저장소(IndexedDB·localStorage·sessionStorage·서비스 워커 캐시)에 저장되며, 이는 이용자 기기 밖으로 보내지 않습니다. 이용자는 브라우저 설정에서 이 사이트 데이터를 지워 언제든 없앨 수 있으며, 이때 이 기기에서는 앱을 처음부터 다시 시작합니다.

제13조 (행태정보·가명정보·민감정보 등)

  • 행태정보의 수집·이용·제공: 해당 없음(방문 통계·광고 도구를 쓰지 않습니다)
  • 추가적인 이용·제공의 판단 기준: 해당 없음
  • 가명정보의 처리: 해당 없음
  • 민감정보의 공개 가능성 및 비공개 선택: 해당 없음(보드는 로그인한 본인만 볼 수 있으며 공개 기능이 없습니다)
  • 국내대리인의 지정: 해당 없음

제14조 (개인정보 보호책임자)

운영자는 개인정보 처리에 관한 업무를 총괄하고 정보주체의 불만 처리와 피해 구제를 위하여 다음과 같이 개인정보 보호책임자를 지정하고 있습니다. 개인정보 열람 청구 등도 아래로 접수합니다.

Summary in English

Ssamboard (Google Drive edition) has no backend server. The operator collects no personal data and uses no analytics, ads or cookies. Board data is stored only in the user's browser and in the hidden app-data folder of the user's own Google Drive.

Google scopes: drive.appdata (store the board and daily backups in the app's hidden folder), openid/email/profile (identify the signed-in account), and optionally drive.file (read Google Sheets the user picks and create Google Forms the user asks for, and read their responses). Google user data is never sold, used for advertising, read by humans, or used to train AI models. It leaves the user's browser and Drive only when the user asks the AI to work on it, in which case the needed content is sent directly from the browser to the AI provider the user chose (Anthropic's Claude API or OpenAI's API) using the user's own API key.

Ssamboard's use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

Users can delete their data at any time by signing out / clearing site data, deleting the app's hidden data in Google Drive settings, and revoking access at myaccount.google.com/permissions. Contact: see Article 14 above.
