쌤보드 개인정보처리방침

구글 드라이브 트랙(이 주소에서 여는 서버 없는 판) · 시행일 2026년 11월 28일

한 줄 요약 — 쌤보드에는 서버가 없습니다. 여러분의 보드 자료는 여러분의 브라우저와 여러분의 구글 드라이브 숨은 앱 폴더에만 저장되고, 쌤보드를 만든 사람은 어떤 자료도 받거나 볼 수 없습니다.

1. 누가 운영하나요

쌤보드는 교사가 만든 공개 소프트웨어(MIT 라이선스)입니다. 이 주소는 GitHub Pages 에 올린 정적 웹페이지로, 앱 코드만 내려 주고 자료를 받는 서버는 없습니다. 아래에서 “운영자”는 이 공개 저장소를 관리하는 사람을 말합니다.

2. 운영자가 모으는 개인정보

없습니다. 운영자는 회원 가입을 받지 않고, 방문 통계·광고·추적 도구도 쓰지 않습니다. 쿠키도 쓰지 않습니다. 다만 이 페이지를 내려 주는 GitHub 은 접속 기록(IP 주소 등)을 남길 수 있으며, 이는 GitHub 개인정보 처리방침을 따릅니다.

4. 구글 사용자 데이터를 쓰는 방법

쌤보드는 아래 권한만 청하고, 적힌 목적에만 씁니다.

  • drive.appdata — 내 드라이브 안에 이 앱만 쓰는 숨은 폴더를 만들어 보드 자료와 백업을 저장합니다. 드라이브의 다른 파일은 보거나 바꿀 수 없습니다.
  • openid · email · profile — 로그인한 계정의 이메일과 이름을 확인합니다.
  • drive.file(설정 → 연결에서 시트·설문을 연결할 때만) — 내가 직접 고른 구글 시트를 읽어 표로 가져오고, 내가 만들라고 한 구글 설문을 만들고 그 응답을 읽습니다. 앱이 만들었거나 내가 고른 파일만 다룰 수 있습니다.

구글에서 받은 데이터는 내 브라우저와 내 드라이브 앱 폴더 밖으로 옮기지 않으며, 예외는 아래 5번처럼 내가 AI 에게 시킨 일에 필요한 내용을 내 열쇠로 Claude 에 보내는 경우뿐입니다. 판매·광고·사람이 읽기·AI 모델 학습에는 쓰지 않습니다.

쌤보드가 Google API 에서 받은 정보를 쓰고 다른 곳으로 옮기는 일은 Google API 서비스 사용자 데이터 정책(제한적 사용 요건 포함)을 지킵니다.

5. 다른 곳으로 보내는 경우(제3자 제공)

운영자는 아무에게도 정보를 제공하지 않습니다. 앱을 쓰는 동안 브라우저가 직접 연결하는 곳은 다음 둘뿐입니다.

  • Google — 로그인, 드라이브 저장, 시트·설문(내가 쓸 때만).
  • Anthropic(Claude) — 내가 Claude API 열쇠를 넣고 AI 에게 일을 시킬 때만, 그 일에 필요한 보드 내용과 내가 쓴 말을 내 열쇠로 보냅니다. 이 내용은 나와 Anthropic 사이의 계약과 Anthropic 개인정보 처리방침을 따릅니다. 열쇠를 넣지 않으면 아무것도 보내지 않습니다.

학생 개인정보를 보드에 적는다면, AI 에게 그 내용을 보내기 전에 소속 학교의 지침을 확인해 주세요.

6. 보관 기간과 지우는 방법

  • 자료는 내가 지울 때까지 내 브라우저와 내 드라이브에 남습니다. 운영자가 따로 보관하는 것은 없습니다.
  • 이 브라우저 자료 지우기: 앱의 로그아웃, 또는 브라우저 설정에서 이 사이트 데이터 삭제.
  • 드라이브 자료 지우기: 구글 드라이브 → 설정 → 앱 관리 → 쌤보드 → “숨겨진 앱 데이터 삭제”.
  • 권한 거두기: 구글 계정 → 서드 파티 앱 및 서비스에서 쌤보드 연결 삭제.

7. 안전하게 지키는 방법

  • 통신은 모두 HTTPS 로 합니다. 페이지에는 보낼 곳을 Google·Anthropic 으로만 좁힌 보안 정책(CSP)을 걸었습니다.
  • AI 가 만든 화면 코드는 바깥과 통신할 수 없는 격리된 틀 안에서만 돌립니다.
  • 앱 코드는 모두 공개되어 있어 누구나 확인할 수 있습니다.

8. 이용자의 권리

자료가 모두 내 브라우저와 내 드라이브에 있으므로, 열람·정정·삭제·처리 정지는 위 6번 방법으로 언제든 직접 할 수 있습니다. 설정 → 드라이브에서 보드 전체를 파일로 내려받을 수도 있습니다.

9. 어린이

쌤보드는 교사 등 성인이 업무에 쓰도록 만든 도구이며, 만 14세 미만 어린이가 직접 쓰는 것을 전제로 하지 않습니다.

10. 문의

개인정보에 관한 문의는 공개 저장소의 Issues에 남겨 주세요. 운영자는 개인정보를 보관하지 않으므로, 문의 글에 이메일·학생 이름 같은 개인정보는 적지 말아 주세요.

11. 바뀔 때

이 방침을 바꾸면 이 페이지의 시행일을 고치고, 바뀐 내용은 공개 저장소의 기록에서 볼 수 있습니다.

Summary in English

Ssamboard (Google Drive edition) has no backend server. The operator collects no personal data and uses no analytics, ads or cookies. Board data is stored only in the user's browser and in the hidden app-data folder of the user's own Google Drive.

Google scopes: drive.appdata (store the board and daily backups in the app's hidden folder), openid/email/profile (identify the signed-in account), and optionally drive.file (read Google Sheets the user picks and create Google Forms the user asks for, and read their responses). Google user data is never sold, used for advertising, read by humans, or used to train AI models. It leaves the user's browser and Drive only when the user asks the AI to work on it, in which case the needed content is sent directly from the browser to Anthropic's Claude API using the user's own API key.

Ssamboard's use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

Users can delete their data at any time by signing out / clearing site data, deleting the app's hidden data in Google Drive settings, and revoking access at myaccount.google.com/permissions. Contact: the Issues page of the public repository linked above.
