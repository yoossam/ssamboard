방법 1 · AI 에게 맡기기 추천

아래 글을 복사해 Claude 나 ChatGPT 에 붙여 넣으세요. 내 컴퓨터에 맞춰 한 단계씩 알려 줍니다.

쌤보드(선생님용 업무 보드) 서버 설치판을 내 컴퓨터에 설치하려고 해. 컴퓨터를 잘 모르는 사람도 따라 할 수 있게 한 번에 한 단계씩만 알려 주고, 내가 결과를 붙여 넣으면 다음 단계로 가 줘.

- 저장소: __REPO_URL__
- 설치 안내: 그 저장소 README 의 "서버 트랙" 부분
- 내 컴퓨터: (맥 / 윈도우 중 하나를 적어 주세요)

순서는 이렇게 해 줘.
1. 먼저 내 컴퓨터에 git 과 Docker Desktop 이 있는지 확인하는 명령을 알려 줘. 없으면 설치법을 알려 줘(윈도우면 WSL 도).
2. 저장소를 받고(git clone) 그 폴더에서 ./scripts/install.sh 를 돌리게 해 줘.
3. 설치 스크립트가 묻는 것은 "1) 이 컴퓨터에서만" 을 고르게 해 줘.
4. 끝나면 나오는 주소(http://localhost:3000)와 '설치 코드'로 첫 화면에서 이름·이메일·암호, PIN 6자리를 정하는 것까지 안내해 줘.
5. 마지막으로 설정 → 일반에서 AI 모델(Claude 또는 GPT)을 고르고 API 키를 넣는 법을 알려 줘.

주의: 비밀 값(.env 파일 내용, API 키, 설치 코드)은 대화에 붙여 넣지 말라고 나에게 알려 줘. 오류가 나면 오류 문장만 보고 원인과 해결을 알려 줘.
Claude · ChatGPT 대화창명령을 알려 주면 내가 터미널에 붙여 넣어 실행
Claude Code · Codex (터미널 AI)터미널에서 열고 붙여 넣으면 AI 가 확인을 받아 직접 실행

방법 2 · 직접 하기 약 10분

필요한 것: Docker Desktop 이 깔린 컴퓨터(맥 · 윈도우는 WSL), AI 를 쓰려면 Claude 또는 OpenAI API 키.

  1. Docker Desktop 설치하고 켜 두기

    docker.com 에서 받아 설치합니다. 윈도우는 WSL 을 먼저 켭니다.

  2. 터미널에서 받고 설치하기 
    git clone __REPO_URL__.git ssamboard
cd ssamboard
./scripts/install.sh

    무엇을 고를지 물으면 1) 이 컴퓨터에서만. 처음에는 몇 분 걸립니다.

  3. 주소 열고 계정 만들기

    끝나면 나오는 http://localhost:3000 을 열고, 같이 나온 설치 코드와 이름 · 이메일 · 암호를 넣습니다. 이어서 보드를 여는 PIN 6자리를 정합니다.

  4. AI 열쇠 넣기

    메뉴 → 설정 → 일반에서 AI 모델(Claude · GPT)을 고르고 그 회사의 API 키를 넣습니다. 열쇠는 서버에만 암호화해 둡니다.

막힐 때

docker 명령을 못 찾음Docker Desktop 을 켜 두었는지 확인하고 터미널을 새로 엽니다.
3000 번을 이미 씀.env 에 APP_PORT=3100 처럼 적고 ./scripts/install.sh 를 다시.
설치 코드를 잊음ssamboard 폴더의 .env 파일에서 SETUP_CODE 줄을 봅니다.
암호 · PIN 을 잊음docker compose exec app jarvis set-password 이메일 · reset-pin 이메일
새 판으로 바꾸기폴더에서 git pull 뒤 ./scripts/install.sh (자료 · 설정은 그대로)
끄기docker compose down (자료는 남습니다)

휴대폰 등 바깥에서 쓰기, 구글 시트 · 설문 연결, 백업은 저장소 설명서에 있습니다. .env 파일은 비밀 값이 들어 있으니 남에게 보내지 마세요.
