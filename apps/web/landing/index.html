구글 드라이브 간편판

이 주소에서 바로 시작하고 싶은 분

  • 구글 계정으로 로그인하면 끝 — 설치할 것이 없습니다.
  • 자료는 내 구글 드라이브의 숨은 앱 폴더에 저장되고, 하루 한 번 백업합니다.
  • 같은 계정이면 컴퓨터·휴대폰 어디서나 같은 보드. 인터넷이 끊겨도 열립니다.
  • 앱을 닫아 둔 동안 저절로 하는 일(일정 알림·시트 자동 맞춤)은 없습니다.

서버 설치판

학교·집 컴퓨터에 직접 설치해 늘 켜 두고 쓰실 분

  • Docker 가 있는 컴퓨터에서 저장소를 받아 설치 명령 한 번(약 10분).
  • 자료는 내 서버의 데이터베이스에 — PIN 잠금, 여러 기기 관리.
  • 일정 10분 전 알림, 시트·설문 자동 다시 읽기, 웹훅까지 모두 됩니다.
  • 저장소를 포크하면 내 것으로 가져가 고쳐 쓸 수 있습니다(MIT).
