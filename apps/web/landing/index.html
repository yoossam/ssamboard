서버 설치판을 내 컴퓨터 없이 한 번에

단추 하나로 클라우드(Render)에 서버와 DB 를 만들고, 바로 쓸 수 있는 내 쌤보드 주소(https://○○.onrender.com)를 받습니다. 명령어를 몰라도 됩니다.

  1. 아래 [Render 로 설치]를 눌러 GitHub 이나 구글로 Render 에 가입·로그인합니다.
  2. 보이는 화면에서 이름을 그대로 두고 Deploy Blueprint(배포)를 누릅니다. 5~10분 기다리면 ssamboard 서비스에 주소가 생깁니다.
  3. Render 의 ssamboard → Environment 에서 SETUP_CODE 값을 복사해, 내 쌤보드 주소 첫 화면에 붙여 넣고 이름·이메일·암호와 PIN 을 정합니다.
Render 로 설치 자세한 안내
AI 에게 한 단계씩 물으며 하기(복사해서 붙여 넣기) 
쌤보드(선생님용 업무 보드)를 Render 에 설치하려고 해. 컴퓨터를 잘 모르는 사람도 따라 할 수 있게 한 번에 한 단계씩만 알려 주고, 내가 화면에 보이는 것을 말하면 다음 단계로 가 줘.

- 설치 단추 주소: https://render.com/deploy?repo=__REPO_URL__
- 저장소: __REPO_URL__ (맨 위의 render.yaml 이 서버와 DB 를 만든다)

순서
1. 위 단추 주소를 열고 Render 에 가입·로그인하는 법(GitHub 이나 구글 계정)을 알려 줘.
2. Blueprint 화면에서 무엇을 누르면 되는지, 끝날 때까지 얼마나 걸리는지 알려 줘.
3. 끝나면 ssamboard 서비스의 주소(https://….onrender.com)를 찾는 곳과, Environment 에서 SETUP_CODE 를 복사하는 곳을 알려 줘.
4. 내 쌤보드 주소를 열어 설치 코드·이름·이메일·암호·PIN 6자리를 정하고, 설정 → 일반에서 AI 열쇠를 넣는 데까지 안내해 줘.
5. 무료 요금제는 시험용(웹은 15분 쉬면 잠들고, 무료 DB 는 30일 뒤 없어짐)이라는 것과, 계속 쓰려면 웹·DB 를 유료 요금제로 올리는 법도 알려 줘.

주의: 비밀 값(SETUP_CODE, MASTER_KEY, API 키, 암호)은 대화에 붙여 넣지 말라고 나에게 알려 줘.

무료 요금제는 써 보기용입니다. 웹은 15분 동안 아무도 안 쓰면 잠들고(다음 접속이 30초쯤 느림), 무료 DB 는 만든 지 30일이 지나면 없어집니다. 계속 쓰려면 Render 에서 웹·DB 를 유료 요금제로 올리세요. 비용은 Render 가 받고, 쌤보드는 따로 돈을 받지 않습니다.
